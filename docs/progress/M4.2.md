# Build 04.2 — Research handoff and financial opportunities

Date: 2026-10-25

## Implemented

- Created a shared deterministic Explore/Recovery fingerprint. Recovery now rejects research
  from a mismatched scenario or work-location context and retains the linked Explore run ID,
  evidence, candidates, outcomes, and questions when the fingerprint matches.
- Browser session reuse now verifies its stored session has the current Explore run ID; an old
  baseline session is replaced instead of hiding newly available research. Plan also explicitly
  identifies baseline-only versus Explore-backed planning.
- Retained every supported research mechanism as a recovery lead, including income
  preservation, budget adjustment, and borrowing-risk pathways. Leads remain outside the
  simulator until a typed, dated effect is supported.
- Added a read-only financial-opportunity analysis to recovery sessions. It reports explicit
  scheduled bills, conservative inferred monthly merchant charges, and variable historical
  categories with classification, confidence, provenance transaction IDs, and forecast status.
- Scheduled obligations are authoritative: matching inferred recurring transactions are marked
  as already represented rather than adding a duplicate forecast charge. Historical groceries
  remain essential variable spending; historical dining can be a conditional discretionary
  opportunity but does not alter the baseline ledger.
- Added separate rent-request and landlord-agreement questions. A date alone no longer implies
  approval; only a stated agreement creates a dated extension effect.

## Fixture audit

- Confirmed scheduled bills: Mobile phone, Electricity, Rent, Auto insurance, and StreamBox
  streaming. The $15 StreamBox historical pattern matches the scheduled subscription and is
  not forecast twice.
- Essential fixed: Housing/Rent, Utilities, Insurance. Essential variable: Groceries,
  Transportation/Gas, Health. Discretionary historical categories: Dining, Shopping, and
  Subscriptions where not already explicitly scheduled.
- Variable spending remains explanatory and conditional. It creates no fictional future debit
  or immediate cash saving.

## Remaining limitations

- Financial opportunities are surfaced as provenance-backed opportunities, not automatically
  executable reductions; a later formula milestone can add narrowly scoped dated effects after
  user confirmation.
- In-memory recovery sessions still disappear after a backend restart. The browser recognizes
  that stale ID and recreates the session, preserving current Explore state but not previous
  answers.
