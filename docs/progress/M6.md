# M6 — UI overhaul

## Implemented

- Rebranded the public interface as **Breakingpoint** with the cream, blue, mint, and ink design system.
- Reworked the four-stage navigation and editorial hierarchy without changing API contracts.
- Made the Stage 1 financial context compact and moved secondary banking context into disclosure UI.
- Rebuilt the 14-node crisis visualization as a top-to-bottom dependency graph.
- Added dependency-aware node reveal, SVG edge tracing, pause/resume, replay, show-full, zoom/fit controls, focus mode, keyboard focus, and reduced-motion behavior.
- Moved shift and payroll mechanics into an optional disclosure while retaining the chart, ledger, bills, and banking details.
- Simplified Stage 3 language and hierarchy while preserving research evidence and resources.
- Replaced the Stage 4 stack of expanded plans with a compact strategy selector and one inspectable plan.

## Verification

- `npm run lint`
- `npm test`

Exact final command results are recorded in the implementation handoff. Graph regression tests cover hierarchical placement, branching, edge-before-node ordering, and exclusion of conditional paths from the realized cascade.

No financial, Nessie, research, recovery-session, or simulation contract was changed. Conditional plans remain conditional, resources and outreach drafts remain available, and historical bank data remains read-only.
