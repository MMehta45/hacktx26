## Implemented

- Added `CustomerSnapshot` schema version 1 with normalized customer, account,
  transaction, category, bill, income forecast, scenario, and provenance records.
- Added a deterministic Maya Rodriguez fixture with 72 purchases, 13 weekly historical
  deposits, four withdrawals, category summaries, a $310 balance, and five dated
  obligations.
- Historical fixture credits and debits both total $8,320. User-entered gross and
  80%-estimated take-home wages remain independent future forecasts: 8× hourly rate per
  shift and 40× weekly.
- Added `GET /api/customer/snapshot` with validation for display name, wage cents, and
  repair quote cents.
- Added a backend-only Nessie client for customers, accounts, merchants, purchases,
  deposits, withdrawals, and readable bills. Errors do not include authenticated URLs
  or response bodies.
- Added `npm run seed:customer` and `npm run seed:customer:reset`. The manifest is saved
  under ignored `backend/.local/`; stable descriptions make normal reruns idempotent.
- Added four navigable frontend stages. The snapshot shows accounts, balance, a filterable
  ledger, recurring/category analysis, essential versus discretionary totals, dated bills,
  gross/net payday forecasts, and a 30-day projected-balance timeline.
- Graph, agent activity/question, and recommended-plan views are explicitly labeled as
  previews and make no claims that analysis, research, or recommendation occurred.
