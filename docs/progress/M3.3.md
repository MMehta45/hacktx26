# Milestone 3.3 — Adaptive research, mechanic reviews, and remote work

## Implemented

- Replaced the fixed four-path execution checklist with validated, scored Gemini
  hypotheses. Baseline hypotheses guarantee remote work, transit, repair, and bill-risk
  coverage without preventing Gemini from proposing other mechanisms.
- Added semantic deduplication, adaptive per-hypothesis budget reservation, authentic
  pathway status/events, and retention of up to eight ranked questions while showing at
  most two initially.
- Changed Maya's fictional profile to Cedarstone Services, Hourly Customer Support
  Specialist, normally onsite. Remote eligibility, equipment, schedule flexibility, and
  make-up hours are explicit unknowns.
- Guaranteed a conditional remote-work candidate and the question “Could you work
  remotely for the next two shifts if your manager approves it?” No shifts are protected
  until later user confirmation.
- Added SerpApi `google_maps_reviews` retrieval using real listing `data_id` values,
  positive/negative pricing-language parsing, transparency evidence, review counts,
  source URLs, confidence, and the specified shop-contact heuristic. Missing review
  evidence scores zero; a written estimate remains required.
- Added a mechanic shortlist UI with address, rating/review count, review evidence,
  confidence, heuristic score, source links, and explicit no-cheapest/no-quote language.
- Reduced baseline transit use to one dated outbound arrival-by and one return request.
  A late returned itinerary now means potentially feasible with an earlier trip or shift
  adjustment, not universal transit infeasibility.
- Kept Nessie reads and `simulate(..., actions=[])` unchanged. No answers, recovery
  combinations, or financial effects were implemented.

## Live provider verification

An explicit refresh on October 24, 2026 used live Nessie, Gemini, and SerpApi. The run
completed with eight SerpApi calls and no warnings across Google web, Maps, Maps
Directions, and Maps Reviews. Gemini proposed additional rent-extension, insurance-
extension, and rideshare-comparison hypotheses beyond the baselines.

The final current-code pass used two transit calls, two web searches selected for bill or
local-aid evidence, one model-selected walking/biking web search, one mechanic listing
search, and two mechanic-review calls. Semantic deduplication removed model restatements
of the baseline remote-work and public-transit hypotheses before allocation.

Actual Maps Reviews evidence was retrieved for:

- Swedish Auto Service, 11008 N Lamar Blvd: listing rating 4.8 with 356 reviews; the
  returned ten-review sample contained one positive fair-price excerpt and no negative
  price excerpt, producing low affordability confidence (contact score 0.387).
- Luu Auto Repair, 8225 N Lamar Blvd: listing rating 4.9 with 184 reviews; the returned
  ten-review sample contained no positive price excerpt and one negative excerpt calling
  the work expensive, producing low affordability confidence (contact score 0.341).

An earlier diagnostic also retrieved reviews for Rising Sun Automotive and Austin DIY
Shop. The latter exposed the need for the final non-repair-facility filter and is no
longer shortlisted or selected for review follow-up.

Neither result proves a repair price, availability, suitability for the unknown failure,
or that a shop is cheapest. A current written estimate is still required.

- Provider results vary and review samples are incomplete, subjective evidence.
- Convenience uses a neutral factor when no mechanic-specific travel route is available.
- A single arrival-by response may omit earlier alternatives; return travel and any shift
  adjustment still require evidence or employer confirmation.
- The API retains additional questions, but answer capture and selective replanning are
  Build 04 work.
- No candidate is applied to cash flow, and no plan combination or ranking exists yet.
