# M4.4 — Deterministic Transit Demo Fixture

## Implemented

- Added a typed, narrowly scoped Route 5 fixture for Maya Rodriguez's documented Austin home, work address, weekday 08:00–16:00 schedule, and America/Chicago timezone.
- The fixture creates paired outbound and return transit evidence for each projected missed weekday: 07:35 outbound departure, 07:52 arrival near work, 16:17 return departure, and $1.25 per direction. Return arrival, stops, walking instructions, and transfers remain unspecified.
- Its provenance is `demo_scenario_assumption`, explicitly not provider-observed or externally verified. The retained Google Maps links are manual navigation aids only.
- Prepended the fixture to the research evidence response, including when live research is unavailable, so an unreliable provider response cannot replace the demo data.
- Converted paired fixture evidence to a $2.50-per-workday, conditional Recovery action. It still requires Maya to report that she can personally use Route 5.
- Updated the simulator so a transit fare is debited only when that transit action is actually needed for its supported shift. A remote-work action covering the same shift, or a usable vehicle, prevents the fare; preserved income remains payroll-dated by the existing simulator.

## Limits

- Route 5 timing and fare are intentional synthetic hackathon assumptions, not a live Google Maps or CapMetro verification. The fixture must not be reused for a different customer, address, schedule, or timezone.
- The user still needs to confirm personal ability to use the commute; no plan presents it as approved or guaranteed.
